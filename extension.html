Browser integration

Every download,
straight to the app.

With the extension loaded, a download in your browser is handed to Master Download Manager the moment it starts — same file, same page, same cookies, no copy in the browser's folder.

Download the extension ↗ Setup, step by step

Supported: Chrome, Chromium, Edge, Brave, Opera, Vivaldi and Firefox.

Setup

Five minutes, once.

The extension is loaded from a folder on your PC, so the browser can only use it while that folder exists. Read step 3 twice.

01

Turn on Developer mode

In Chrome, Edge, Brave, Opera or Vivaldi open the extensions page and switch on Developer mode (top right). In Firefox open about:debugging and choose This Firefox.

02

Download the extension

On the GitHub Releases page take MDM_Browser_Extension.zip from the latest release. Firefox has its own package on the same release: MDM_Browser_Extension_Firefox.xpi - load it the same way in step 4.

03

Extract it — and keep the folder

Right-click the zip, Extract All, and put the folder somewhere permanent (for example Documents\MDM Browser Extension). The browser loads the extension from that folder every time: if you move or delete it, the extension disappears and you will have to load it again.

04

Load the unpacked extension

Chrome and the others: Load unpacked, then pick the folder you extracted. Firefox: Load Temporary Add-on, then pick the manifest.json inside that folder.

05

Run the app

Start Master Download Manager and let it sit in the notification area — the extension talks to it locally. Nothing else to configure; the app registers the connection with your browser itself.

06

It says Connected — you are done

Open the extension's popup: when it reads Connected, downloads in that browser go to MDM. If it says Disconnected, start the app first, then reopen the popup.

Good to know

Three things people ask afterwards.

Keep the folder. This is an unpacked extension: the browser reads it from disk on every start. Move it and the extension is gone; delete it and you repeat step 2.

Developer mode stays on. Chrome shows a small "developer mode extensions" notice at startup. That is normal for an extension installed this way — the extension itself needs no extra permissions beyond downloads, cookies and the local connection to the app.

Firefox loads it for the session. A temporary add-on has to be added again after Firefox restarts — repeat step 4, from the same folder.
