Everything in one place

One manager. Every kind of download.

Sixteen things that are actually in the app — not a feature list written by marketing.

Many connections per file

A file is split into segments and fetched over several connections at once, then rejoined. The number is yours to set, per file or per server.

Resume that survives a crash

The part file sits beside the destination and carries its own map of what is done. Close the app, lose the network, reboot — it continues where it stopped.

Browser capture

Chrome, Chromium, Edge, Brave, Opera, Vivaldi and Firefox hand downloads straight to the app — with the page, the referrer and the cookies it needs.

Video and audio downloads

Paste a page or press the video button: formats are looked up, you pick quality and container, and FFmpeg muxes video and audio into one file.

Live streams

Twitch, YouTube live and the rest through Streamlink, recorded to disk while the stream runs.

Image galleries

Whole galleries through gallery-dl, filed into folders named after the site and the set — not a pile of files in Downloads.

BitTorrent, same list

Magnets and .torrent files download next to everything else, with seeding limits, blocklists, port forwarding and optional proxy.

Link grabber

Reads a page and lists every link on it, filtered by type — tick what you want and queue the batch in one click.

Scheduler and queues

Start and stop queues at a time, on chosen days; retry what fails, keep a later queue, and a separate batch queue for grabs.

Speed limits, both ways

A limit per download and a global one, for downloads and uploads — a big transfer cannot swallow the whole line.

Checksums

Verify a finished file against an MD5, SHA-1 or SHA-256 you were given — inside the app, before you trust it.

Archives, unpacked

.zip, .tar and .xz extract themselves after the download; RAR and 7z go through a 7-Zip you already have.

Command line, local API, MCP

Scripts get the classic /d /p /f switches, a terminal downloader with JSON output, a local HTTP API behind a token, and an MCP server for AI assistants.

85 languages, themes, scaling

The whole interface translated, light and dark looks, interface size and font weight, keyboard navigation and the system's accessibility tree.

Debrid and site logins

Real-Debrid, AllDebrid and Premiumize can fetch a link for you; per-site credentials are kept in the Windows keychain, never in a text file.

No telemetry, no account

No analytics, no ads, no sign-in, no bundled offers. The app talks to the servers you point it at and its own release list — nothing else.

How it works

What happens between a link and a finished file.

No hand-waving: this is the actual path a download takes through the app.

01

The link is checked first

The app asks the server for the file's name, size, type and whether it accepts ranges. Sizes, speed and the resume plan all come from that answer — before a byte is written.

02

The file is split

A part file is created beside the destination at full size, and each connection writes its own range into it. Segments finish in whatever order the network allows.

03

A dropped connection is normal

The segment that failed is reopened with a range request and carries on. The part file records what is already there, so closing the app or losing the network costs nothing.

04

The file is finished in place

When the last segment lands the part file is renamed to the real name in the same folder — no copy, no temporary drive, nothing left behind. Optional: verify a checksum, then extract an archive.

05

Video takes a different road

A video page is read by yt-dlp first. If it has no reader for that site, lux is tried, then Streamlink for a live stream, then Ember. FFmpeg joins the chosen video and audio into one file.

06

Everything lands in one list

Files, torrents, videos and galleries share the same queue, the same speed limits, the same scheduler and the same right-click menu — one place to look.

Download

Windows 10 and 11, 64-bit.

Every release is a full bundle: the engine, the browser integration and all the video, gallery and muxing helpers are inside.

Installer

For the current user: Start menu entry, optional browser integration, uninstall entry. Nothing is installed system-wide and no administrator prompt is needed.

Portable

A folder you can put anywhere: settings, download list, logs and helpers stay inside it, and nothing is written to your profile or the registry.
