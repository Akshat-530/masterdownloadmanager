# Master Download Manager — website

The site for Master Download Manager, a free, open-source download manager for Windows, macOS
and Linux.

Plain HTML and CSS, no build step and no external requests: open `index.html` to see it. Pushing
to `main` deploys it with GitHub Pages (`.github/workflows/pages.yml`).

| File | What it is |
|---|---|
| `index.html` | the page |
| `styles.css` | its styles (dark and light, following the system) |
| `404.html` | not-found page |
| `.github/workflows/pages.yml` | the deploy |

Copy lives in `index.html`; there is no templating. Keep it factual: features the app has, no
comparisons with other products, no performance claims that are not reproduced in the repository.

The site's own text and code are GPL-3.0-or-later, the same as the app.
